Try Frappe and ERPNext without setting up a server

Frappe Lab starts a temporary, ready-to-use Frappe site in your browser. Use it to see a version, show a demo, test an idea or build a custom app. When you are done, delete it.

Get started in three steps

  1. Have a free GitHub account Frappe Lab runs on GitHub Codespaces, so you need a GitHub account. It is free to create and takes a couple of minutes.

    Create a free GitHub account

  2. Choose a stack and press Launch GitHub will ask you to confirm creating a Codespace. Accept the defaults, or pick the machine size GitHub suggests.
  3. Wait, then open the site The first start takes roughly 8 to 10 minutes while Frappe is installed. Watch the progress in the Codespace terminal. When it finishes, open the Ports tab, then open the address for port 8000 and sign in with the demo login shown below.

Good to know

  • It is temporary. A Codespace stops when idle and is a disposable workspace, not a hosted server. Do not keep important data in it.
  • It uses your GitHub allowance. Free accounts include a monthly amount of Codespaces time and storage, and larger machines use it faster. See GitHub's current limits. Without a payment method on file, Codespaces stops when the allowance runs out.
  • Stop it when you are done. Open github.com/codespaces to stop or delete a Codespace.
  • The site is private by default. Only your GitHub account can open it. Sharing it with a client means making the port public in the Ports tab, and some organisations block that.

Questions

Do I need to install anything?
No. Everything runs in the browser through GitHub Codespaces.
Can I choose another version or add apps?
Yes. Stacks are small files in config/presets. Change the branches or add an app, and the setup follows. Not every combination of app branches is compatible.
Is this an official Frappe or ERPNext product?
No. Frappe Lab is an independent community project.
